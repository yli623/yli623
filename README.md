## Hi there 👋

I'm a principal technical product manager at Amazon with more than ten years of building platform and AI products. I believe the best way to understand what AI can do is to build with it, so I build with it daily, at work and outside it.

This page collects things I've built for myself. Each project's README is written as a short case study: the problem, the decisions, and what I learned.

### Projects

**[Flight Tracker](https://github.com/yli623/flight-tracker)** — A Raspberry Pi and e-ink picture frame that shows the plane flying overhead: airline, route, aircraft, and which way to look. The interesting part was finding that a free route database was right for only 1 in 5 aircraft, then building checks that test each route against where the plane actually is. *Python · Raspberry Pi · built with Claude Code*

**[STAR Debrief](https://github.com/yli623/star-debrief-skill)** — An agent skill that runs a weekly debrief: it brings evidence of your week, interviews you about one piece of real work, and files it as an interview-ready STAR story with a resume bullet. I built it after a passive "log your wins" doc stayed empty. *Agent skill · works with Claude Code and other agents*

### How I work

- **Measure before trusting.** Data that looks authoritative gets tested against something observable before it reaches a user.
- **Prototype at real size.** I check the experience before spending on the build, whether that's a printed mock-up taped to a wall or a working preview in a browser.
- **Design for how people actually behave.** If a tool waits for people to use it, they won't; build it to come to them.
